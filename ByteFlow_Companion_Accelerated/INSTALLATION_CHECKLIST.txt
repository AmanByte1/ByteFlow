TROUBLESHOOTING ⚠️
═══════════════════════════════════════════════════════════════════

❌ "Port 5000 already in use"
  → Kill existing process:  netstat -ano | findstr :5000
  → Or change port in code

❌ "Flask not found"
  → Install:  pip install flask flask-cors flask-limiter

❌ "Accelerator not found"  
  → Normal - app still works  
  → To enable:  pip install local-ai-accelerator

❌ "Connection refused"
  → Check server is running in terminal
  → Try http://127.0.0.1:5000 instead
  → Wait 2 seconds after starting

❌ "Module local_ai_accelerator not found"
  → Install:  pip install local-ai-accelerator
  → Restart server

See README_ACCELERATED_COMPANION.md for detailed troubleshooting
